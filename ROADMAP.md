# HomeLab Roadmap

## Vision

Celem HomeLaba jest stworzenie niezawodnej platformy do:

- przechowywania danych,
- automatyzacji,
- środowiska AI,
- pracy naukowej,
- monitoringu infrastruktury,
- usług domowych.

---

## Current State

### Infrastructure

- ✅ Ubuntu Server 24.04 LTS
- ✅ Docker
- ✅ ZFS Mirror
- ✅ Snapshoty Sanoid
- ✅ SMART monitoring

### Storage

- ✅ Nextcloud
- ✅ Time Machine (2 komputery)
- ✅ Fedora Backup Share
- ✅ Zotero przez Nextcloud WebDAV

### Monitoring

- ✅ Homepage
- ✅ Beszel
- ✅ Uptime Kuma

### Network

- ✅ Pi-hole
- ✅ Unbound
- ✅ Nginx Proxy Manager

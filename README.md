# HomeLab

Repozytorium zawiera dokumentację oraz konfigurację mojego HomeLaba.

## Cel

HomeLab jest centralną platformą IT wykorzystywaną do:

- prywatnej chmury plików,
- zarządzania dokumentami,
- przechowywania zdjęć,
- środowiska AI,
- automatyzacji,
- monitoringu,
- backupów,
- usług sieciowych.
